
AI-SP产品展示素材包
====================

医视界

文件说明
--------
1. AI-SP产品介绍-销售版.html
   - 面向客户的产品介绍PPT（网页版）
   - 包含8页内容：封面、行业痛点、核心功能演示、应用成效、竞争优势、联系我们
   - 适合销售向客户展示

2. AI-SP操作教程-手机版.html
   - 面向用户的操作教程
   - 手机适配设计
   - 按业务流程划分：系统登录、管理端、训练、考试
   - 每个模块都标注了适用对象（管理员/学员/考官/所有人）
   - 包含完整的操作流程视频和图文说明
   - 适合直接发给客户自行学习

3. 视频文件（最新版本）
   - APP端操作.mp4 - 电子书包APP登录和操作
   - 01登录+web训练.mp4 - Web端登录和训练
   - 02生成病例.mp4 - 病例生成操作
   - 04考核-创建考试.mp4 - 创建考试操作
   - 05考生端设置和操作.mp4 - 考生端完整操作
   - 06考官评分操作.mp4 - 考官评分操作
   - 07考核-查看考试成绩.mp4 - 查看考试成绩

使用方法
--------
1. 直接用浏览器打开.html文件即可查看
2. 视频需要手动点击播放，默认开启声音
3. 可以拷贝整个文件夹发送给客户
4. 所有素材已统一整理在本文件夹中

技术说明
--------
- 所有HTML文件无需安装任何软件
- 支持主流浏览器：Chrome、Firefox、Safari、Edge
- 手机版已做响应式适配
- 视频播放需要浏览器支持HTML5 video
